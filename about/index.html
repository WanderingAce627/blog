关于这个博客

我是 Harry。这里是我在互联网上的一块自留地，用来放两类东西：一类是技术笔记——踩过的坑、跑通的方案、值得写下来下次不用再查的细节； 另一类是随笔——读过的东西、走过的路，以及一些还没想清楚的想法。

把这两类放在一起，不是偷懒。写代码和写字看起来是两件事，但它们用的是同一种能力： 把一团模糊的东西整理成别人（以及三个月后的自己）能看懂的样子。

为什么自己搭

把文章放在别人的平台上当然更省事，但代价是：排版不由你、导出不由你、 哪天平台关停也不由你。这个站点的全部内容就是一堆 Markdown 文件， 存在我自己的 Git 仓库里——哪怕明天换掉整个前端，文章也一个字不会丢。

文字应该比承载它的工具活得久。

这个站是怎么搭的

  • 框架：Astro，纯静态输出，没有多余的 JavaScript。
  • 写作：Markdown，放进仓库即自动发布。
  • 部署：GitHub Actions 构建后推到 GitHub Pages，零服务器成本。
  • 字体：全部使用系统字体，不加载任何外部资源。

想自己也搭一个？可以看这篇：用 Astro 和 GitHub Pages 搭一个不用管服务器的博客。
